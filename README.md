### How to create new project 👏

1. Add a new folder (with project name) in the root of this repo (you can use `/starter`)
2. Create a new project in Studio
3. Go to Terminal, write `ln -s `
4. Drag new project folder to the Terminal, add a `space`
5. Drag the new studio project folder to the Terminal
6. Copy the content from `/wp-content` to the symlink folder
7. Rename the the symlink folder `wp-content`
8. Delete the original `/wp-content` folder
9. **Create a new branch, and start coding!**
